# Changelog

## 0.1.0 (unreleased)

First public version: images and labels for web pages.

- `decide`: the Article 50(4) checklist (deep fakes, public-interest text, editorial review, creative works, audio) with the EU icon to use, placement, accessibility notes and the label sentence. Based on the AI Act, the Commission's Article 50 Guidelines (20 July 2026) and the Code of Practice on Transparency of AI-Generated Content. When the deciding fact is missing (`--realistic` for image, video and audio; `--public-interest`, then `--editorial-review` for public-interest text) it returns `UNKNOWN` with one question, names the argument in `missing` and exits with code 2 instead of guessing.
- `decide` prints a short answer by default: a one-line verdict (also the `verdict` field), the next command to run, the label, where to put it and what screen readers need. `--explain` adds the basis, notes and sources; `--json` is always complete. The label sentence is the `disclosure` field.
- `decide` wording checked against the sources: territorial scope and what counts as professional use (Guidelines paras 13 and 19-20), video labels kept for the whole video or repeated (Code Sub-measure 1.2.2(b)), repeated spoken disclaimers in long audio (Sub-measure 1.2.3) with the example in the label language, spoken and transcript routes for blind viewers (WCAG 1.2.5, 1.2.1), no animation (WCAG 2.2.2), an explanation of the human-made mark (Code Measure 2.1) and the Unfair Commercial Practices Directive for false human-made claims.
- `render`: labels with the official basic EU icon, text in English or Polish, content-type icons and an optional "Made by a human" part; SVG (with `lang`), PNG or WebP; 4.5:1 text contrast on any backdrop. `--format html` writes the label as real text with a stylesheet (`--css`) that follows the page's colour scheme (`light-dark()`, with a fallback for older browsers) and forced colours, wraps whole words in narrow columns and keeps type at 12 px or more. The SVG scales down in a narrow container. Spaced capitals are never set below 10 px.
- `stamp`: burns a label into one JPG, PNG, WebP, AVIF or TIFF file, sized for the image (about 6% of the shorter side, at least 2.5% of the longer side, 28 to 512 px) and in the theme that stands out more from the image. Keeps the EXIF, colour profile and XMP of the original and adds an IPTC DigitalSourceType to the XMP. Refuses to overwrite an output or to stamp a labelled file again unless you pass `--force`; every stamp writes the project's XMP marker (also for human-made labels and with `--no-metadata`), so a renamed labelled file is refused too. Writes through a temporary file and refuses a second parallel write to the same output. Folders, animated images and GIF output are refused with what to do instead. The summary names the pill colour and warns when `--allow-low-contrast` drops below 4.5:1 (`wcag: false` in the result).
- Alt text: `--description` puts what the image shows before the label sentence; results carry both `alt` and `disclosure` (the sentence alone). Without a description `alt` is null and `altMissing` says what to pass; `render` adds `labelAlt` and prints a ready `<img>` line for a label image.
- Languages: all 24 EU language codes. English and Polish have built-in wording; the others take `--text` (and `--human-text`) and tag the SVG and HTML with that language.
- Input checks: stray words (an unquoted `--text`) and fractional heights are refused.
- `--minimal`: no text, only the author mark (EU "AI" disc, or a hand in the same disc) and the content-type icons, down to 20 px. Labels with text are at least 24 px tall.
- `eu`: the official EU icons, unchanged. `icons`: the content-type icons.
- MCP server (`decide_label`, `render_label`, `stamp_image`, `eu_icon`) with strict arguments and tool annotations, Claude Code plugin and skill.
